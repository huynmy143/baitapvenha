## 2. Mục tiêu thực hiện

Ba bài Lab tập trung vào nền tảng JavaScript, thao tác DOM và xử lý sự kiện, sau đó sử dụng jQuery để xây dựng các tương tác trên website. Bài thực hành giúp rèn luyện cách tổ chức mã nguồn HTML, CSS, JavaScript và sử dụng công cụ của trình duyệt để kiểm tra kết quả, xác định lỗi.

Những kỹ thuật này có thể vận dụng vào website thương mại điện tử như kiểm tra biểu mẫu đăng ký, thay đổi số lượng sản phẩm trong giỏ hàng, cập nhật nội dung sản phẩm và tạo hiệu ứng tương tác. Mã nguồn được tổ chức trong repository đã sử dụng cho các bài thực hành trước của học phần.

## 4. Nội dung các bài Lab

### Lab 08 – JavaScript 1: Language Foundations

Lab 08 gồm 11 Exercise, từ 8.1 đến 8.11, giới thiệu cách sử dụng JavaScript trong HTML, liên kết file JavaScript ngoài và sử dụng thẻ `noscript`. Các bài tiếp theo thực hành Browser Console, đối tượng có sẵn, mảng, hàm, hàm như đối tượng, tạo đối tượng và mảng đối tượng.

[Mở danh sách bài Lab 08](Lab08/index.html).

### Lab 09 – JavaScript 2: DOM and Events

Lab 09 gồm 8 Exercise, từ 9.1 đến 9.8, tập trung vào lựa chọn phần tử, quan hệ giữa các nút DOM và thay đổi nội dung trang. Các bài thực hành tiếp tục với xử lý sự kiện, sự kiện tải trang, gỡ lỗi sự kiện, làm việc với biểu mẫu và kiểm tra dữ liệu nhập.

[Mở danh sách bài Lab 09](Lab09/index.html).

### Lab 10 – JavaScript 3: jQuery

Lab 10 gồm 10 mục Exercise, từ 10.1 đến 10.10, giới thiệu cách nạp thư viện jQuery, sử dụng bộ chọn cơ bản và nâng cao, xử lý sự kiện và chèn phần tử DOM. Các bài còn lại thực hành hiệu ứng, xem trước ảnh, hiệu ứng nối tiếp, gửi yêu cầu GET và xử lý phản hồi bằng jqXHR.

Trong source hiện tại, Exercise 10.1 và 10.2 cùng dẫn đến file `lab10-walkthrough01.html`.

[Mở danh sách bài Lab 10](Lab10/index.html).

## 6. Hướng dẫn truy cập bài thực hành

### Truy cập trực tuyến

1. Mở đường dẫn trang chủ GitHub Pages ở trên.
2. Xem thông tin sinh viên và phần giới thiệu bài thực hành.
3. Chọn **Truy cập Lab 08**, **Truy cập Lab 09** hoặc **Truy cập Lab 10**.
4. Chọn Exercise trong trang danh sách để mở bài tương ứng.
5. Thực hiện thao tác theo nội dung bài: nhấp chuột, rê chuột, nhập biểu mẫu hoặc quan sát hiệu ứng. Với bài có kết quả trong Console, mở công cụ dành cho nhà phát triển bằng phím **F12**, rồi chọn **Console**.
6. Tại trang danh sách của mỗi Lab, chọn **Về trang hồ sơ** để trở lại trang chủ.

### Chạy trên máy tính

1. Tải source từ repository hoặc clone bằng lệnh:

   ```bash
   git clone https://github.com/huynmy143/baitapvenha.git
   ```

2. Mở thư mục `baitapvenha` bằng Visual Studio Code.
3. Nếu đã cài tiện ích Live Server, nhấp chuột phải vào `buoi4/index.html` và chọn **Open with Live Server**.
4. Truy cập các Lab và Exercise từ giao diện trang chủ.
